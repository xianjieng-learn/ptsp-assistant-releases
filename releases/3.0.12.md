# PTSP Assistant v3.0.12

Rilis ini menjadi pengujian publikasi otomatis pertama untuk PTSP Assistant.

## Perubahan

- Mengaktifkan publikasi dan pembaruan otomatis melalui GitHub Release.
- Memuat seluruh perbaikan v3.0.11 untuk Preview Autofill eCourt/SIPP.
- Memulihkan tombol konversi DOCX ke PDF.
- Memuat perbaikan antrean otomatis pengambilan SKUM SIPP dan pembuatan flyer Santrimo.
- Tetap memvalidasi nama Penggugat/Pemohon 1 sebelum data perkara digunakan.

## Kompatibilitas

Hotfix otomatis ini ditujukan untuk instalasi PTSP Assistant v3.0.10 atau lebih baru yang sudah memiliki Native Host updater terintegrasi v1.14.1.

Asset release akan dibangun dan ditandatangani checksum-nya oleh GitHub Actions sebelum `stable/latest.json` diaktifkan.
