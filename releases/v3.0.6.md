# PTSP Assistant v3.0.6

Tanggal build: 31 Juli 2026.

## Perbaikan updater

- Memperjelas kondisi ketika versi lokal lebih baru daripada manifest stable GitHub.
- Tidak lagi menampilkan catatan perubahan versi lama ketika build lokal lebih baru.
- Status updater membedakan Native Host lama, updater aktif, dan host tidak tersambung.
- Installer/hotfix menulis registrasi Native Messaging pada registry Windows 32-bit dan 64-bit.
- Installer memverifikasi registry serta respons `suite_update_status` sebelum menyatakan berhasil.

## Pengaman identitas e-Court

- Halaman detail pendaftaran e-Court membaca nama Penggugat/Pemohon/Pelawan pertama.
- Nama dibandingkan secara persis setelah normalisasi kapitalisasi, spasi, tanda baca, dan aksen.
- Jika nama berbeda atau tidak terbaca, nomor pendaftaran online, nomor pembayaran, efiling ID, dan nomor perkara dari halaman tersebut tidak dipasangkan ke pekerjaan.
- Ketidaksesuaian dicatat pada riwayat pekerjaan.
