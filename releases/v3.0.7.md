# PTSP Assistant v3.0.7

Tanggal build: 31 Juli 2026.

## Perbaikan sinkronisasi perkara aktif

- Halaman detail e-Court memprioritaskan pekerjaan yang sedang dipilih pada Side Panel.
- Jika nama Penggugat/Pemohon/Pelawan 1 cocok persis setelah normalisasi, nomor pendaftaran online, nomor pembayaran, efiling ID, dan nomor perkara dari halaman aktif menggantikan nilai lama pada pekerjaan.
- Jika nama berbeda atau tidak terbaca, seluruh data identitas perkara dari halaman e-Court ditolak dan nilai pekerjaan tidak diubah.
- Pergantian data dicatat sebagai `ecourt-registration-data-replaced` pada riwayat pekerjaan.
- Status registrasi otomatis lama direset ketika konteks perkara diganti dari halaman e-Court yang telah lolos verifikasi nama.
