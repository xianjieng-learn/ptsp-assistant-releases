# PTSP Assistant v3.0.8

## Perbaikan deteksi detail SIPP

- Halaman detail perkara SIPP v6.2.4 kini dikenali dari struktur Data Umum, bukan hanya dari tombol **Edit Data Umum**.
- Tanggal pendaftaran, klasifikasi perkara, nomor urut, pihak utama, posita, petitum, dan data perkawinan digunakan untuk memeriksa kelengkapan Data Umum.
- Baris anak pada tabel bersarang **Data Anak** kini terdeteksi pada tampilan baca-saja.
- Nama Penggugat/Pemohon/Pelawan 1 dari SIPP harus cocok dengan pekerjaan aktif sebelum status atau proses otomatis diperbarui.
- Setelah Data Umum lengkap dan Data Anak yang diperlukan terdeteksi, proses melanjutkan pengambilan SKUM dari SIPP, verifikasi nama, pembuatan flyer, dan persiapan WhatsApp.
- Pemindaian halaman berulang dikunci agar tidak menjalankan SKUM dan flyer dua kali.
