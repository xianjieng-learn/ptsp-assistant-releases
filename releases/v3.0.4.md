# PTSP Assistant v3.0.4

Tanggal publikasi manifest: 31 Juli 2026.

## Fitur utama

- Pemeriksaan versi stable otomatis saat Side Panel dibuka dan setiap 12 jam.
- Banner **Pembaruan tersedia** dengan tombol **Update Sekarang**.
- Panel pembaruan pada menu **Status Sistem**.
- PTSP Update Agent Native Messaging `com.xianjieng.ptsp_updater`.
- Verifikasi sumber unduhan, batas ukuran, dan SHA-256 sebelum installer dijalankan.
- Status pemasangan dan tombol **Muat Ulang** setelah update selesai.
- Installer mempertahankan credential, pekerjaan, pengaturan, serta konfigurasi sharing yang sudah ada.
- Hotfix pengambilan SKUM dari SIPP pada v3.0.3 tetap dipertahankan.
